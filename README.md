# Titanic ML Model Deployment and FastAPI Serving

## Project Overview
This project trains a machine-learning classification pipeline using the Kaggle Titanic `train.csv` dataset. It evaluates the model, saves the complete pipeline with Joblib, demonstrates online, batch, and streaming inference, and serves predictions through a FastAPI REST API.

## Dataset
Official dataset: https://www.kaggle.com/competitions/titanic/data

Download `train.csv` from the Kaggle competition and place it in the project directory. This project uses the specified `train.csv` dataset.

## Features Used
- Passenger class (`Pclass`)
- Sex (`Sex`)
- Age (`Age`)
- Siblings/spouses aboard (`SibSp`)
- Parents/children aboard (`Parch`)
- Fare (`Fare`)
- Embarkation port (`Embarked`)

## Preprocessing and Model
- Missing numeric values are filled using the median.
- Missing categorical values are filled using the most frequent value.
- Numeric features are standardized.
- Categorical features are one-hot encoded.
- A Random Forest classifier is trained in a scikit-learn pipeline.
- The complete pipeline is saved as `model.pkl`.

## Project Files
- `train_model.py` — preprocesses the data, trains the model, evaluates accuracy, and saves the pipeline.
- `online_inference.py` — predicts one reserved unseen passenger.
- `batch_inference.py` — predicts 20 reserved unseen passengers and creates `batch_predictions.csv`.
- `streaming_inference.py` — processes 10 reserved unseen passengers one at a time with a one-second delay.
- `app.py` — FastAPI application with `/health` and `/predict` endpoints.
- `client.py` — sends health and prediction requests to the API.
- `model.pkl` — saved trained pipeline generated by `train_model.py`.
- `unseen_records.csv` — reserved records used for inference demonstrations.
- `batch_predictions.csv` — batch prediction output.
- `metrics.json` — model evaluation metric output.
- `requirements.txt` — Python dependencies.
- `report.pdf` — assignment observation report.
- `screenshots/` — screenshots of inference and API testing.

## Setup
Python 3.10 or later is recommended.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Install dependencies:
```bash
python -m pip install -r requirements.txt
```

## Run the Project
Run these commands from the project directory in order:

```bash
python train_model.py
python online_inference.py
python batch_inference.py
python streaming_inference.py
```

Training creates `model.pkl`, `unseen_records.csv`, and `metrics.json`. The inference scripts load the saved model and do not retrain it.

## Start FastAPI
```bash
uvicorn app:app --reload
```

Open these local URLs in a browser:
- Health check: http://127.0.0.1:8000/health
- Swagger UI: http://127.0.0.1:8000/docs

Use Swagger UI to test a valid `/predict` request. For validation testing, use an invalid value such as `Pclass: 8`; the API should return HTTP 422.
